# Category Hierarchy Design

## Current Categories in JSON
Entries have these category fields:
- Platform, Discoveries, Tools, Research, Workflows

## Proposed Hierarchy

### platform
- API
  - Error codes
  - Rate limiting
  - Authentication
- LLM
  - Models
  - Capabilities
  - Constraints

### discovery
- Bugs
- Features
- Patterns
- Limitations

### tool_fix
- Validation
- Documentation
- Testing
- Security

### research
- Frameworks
- Patterns
- Studies
- Surveys

### tool_limitation
- Constraints
- Edge cases
- Bugs

### workflow
- Processes
- Automation
- Systems

### tool_improvement
- Optimization
- Refactor
- Extension
