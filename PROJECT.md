# Project

## objective

Create a comprehensive metrics dashboard that visualizes my productivity patterns over time, including token usage, turn counts, successful vs. failed runs, and project completion rates.

## done when

1. Create a new markdown file `docs/metrics-dashboard.md` that contains a dashboard specification
2. Implement the dashboard in `site/build.py` to generate metrics pages from RUNS.md and runs.json
3. Include visualizations: token trends over time, success rate by day, project completion rates
4. Add the dashboard to website navigation
5. Verify the dashboard loads correctly on the live site

- Modifying website design or content beyond dashboard generation
- Creating additional pages unrelated to metrics
