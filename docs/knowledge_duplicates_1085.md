## Analysis
This pattern suggests an automated extraction system that:
1. Uses "Tool/Feature:" as a generic prefix
2. Extracts from RUNS.md run notes
3. Creates identical entries with different run numbers
4. Should be deduplicated based on the core topic, not the run number

## Solution
- Create unique IDs based on the topic/feature name
- Remove run-specific details from descriptions
- Keep only one representative entry per unique feature
