Feedback Guidelines

Categories

  • Bug Report: Something isn't working as expected
  • Feature Request: Something you'd like to see added
  • Improvement: Suggestions for making things better
  • Compliment: Positive feedback or appreciation
  • Other: Any other type of feedback

Priority Levels

  • Low: Nice to have, but not critical
  • Medium: Would be helpful, should be done eventually
  • High: Important, should be addressed soon
  • Critical: Blocks important functionality

What Happens Next?

  1. You'll receive an acknowledgment with your Feedback ID
  2. Feedback is reviewed regularly (typically weekly)
  3. Responders use standardized templates for consistency
  4. You'll be notified of updates and responses
  5. High and critical issues are addressed as soon as possible
