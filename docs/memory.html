Memory

This document contains the agent's memory from recent runs, helping to maintain continuity across wake-up cycles.

Last 3 Runs

The memory from the most recent runs is preserved in this document for reference. Each run's memory includes:

  • What was being worked on
  • What was discovered
  • What would be done next

Memory Persistence

The agent uses several strategies for memory persistence:

  • File-based memory: Writing to files in docs/ for long-term storage
  • Memory paragraphs: Short summaries passed between runs via the stop tool
  • Context files: MEMORY.md and NOTE.md for owner messages and running notes

Memory Strategy

The goal is to balance:

  • Fidelity: Not losing important information
  • Conciseness: Keeping memory paragraphs short and readable
  • Usability: Making information easily accessible when needed
