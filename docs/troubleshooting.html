Agent Issues

Agent Won't Start

Symptom: Running python drift.py fails with an error.

Possible Causes:

  1. Import Errors bash # Check Python version python --version # Should be 3.10+

# Check for missing dependencies pip install -r requirements.txt ```

  1. Environment Variables Not Set bash # Verify GH_TOKEN is set (optional, for GitHub tools) echo $GH_TOKEN

  2. File Permission Issues bash # Check permissions on key files ls -la drift.py ls -la agent/

Solution: Check the error message, ensure dependencies are installed, and verify Python version.

Agent Gets Stuck in Infinite Loop

Symptom: The agent keeps making the same changes or never stops.

Possible Causes:

  1. Incomplete Project Definition - The project in PROJECT.md has no clear "Done when" criteria - The agent cannot determine when to stop

  2. Insufficient Memory Constraints - The agent is running out of context and makes poor decisions

  3. Tool Errors - A tool is failing silently and returning invalid data

Solution:

  1. Read PROJECT.md and ensure it has clear, verifiable completion criteria
  2. Monitor the agent's progress by checking RUNS.md and MEMORY.md
  3. Check for tool errors in the agent's output
  4. If stuck for too long, press Ctrl+C and manually call summarize

Agent Makes Repeated Changes

Symptom: The agent keeps making the same edits without progress.

Possible Causes:

  1. Edit Overlap - The agent is editing files that get overwritten by subsequent edits

  2. Inconsistent State - The agent is reading outdated information

  3. Lack of Verification - The agent isn't checking if its changes are correct

Solution:

  1. Check if multiple files are being edited simultaneously
  2. Verify the agent is reading up-to-date files
  3. Add validation steps between edits
  4. Use validate_git_status to check for uncommitted changes

Site Build Issues

Site Build Fails

Symptom: python site/build.py fails with an error.

Common Causes:

  1. Missing Dependencies bash # Install dependencies pip install -r requirements.txt

  2. Python Syntax Errors bash # Check for syntax errors python -m py_compile site/build.py

  3. File Not Found - Check that required source files exist in docs/

  4. Markdown Parsing Errors - Check for malformed markdown in docs/*.md files

Solution: Check the error message and ensure all dependencies are installed and source files exist.

Site Validation Fails

Symptom: python site/check_site.py reports failures.

Common Issues:

  1. Missing HTML Files - Run python site/build.py to regenerate HTML - Check that markdown files exist in docs/

  2. Broken Links - Check docs/_config.yml for incorrect navigation links - Verify all markdown files exist and have correct extensions

  3. File Naming Issues - Blog posts should follow pattern: YYYY-MM-DD-words-with-dashes.md - Check that all markdown files have corresponding HTML files

  4. Duplicate Posts - Check docs/_posts/ for duplicate markdown files

Solution: Fix the specific issue mentioned in the validation output.

Live Site Has Issues

Symptom: python site/check_site.py --live reports failures on the published site.

Common Causes:

  1. Build Not Published - You need to commit and push your changes - GitHub Pages may take 1-2 minutes to update

  2. Caching Issues - Clear browser cache - Wait a few minutes for GitHub Pages to propagate

  3. Missing Build Artifacts - Ensure all required files exist locally before committing - Run python site/build.py locally first

Solution:

  1. Verify your local build works: python site/check_site.py
  2. Commit and push changes: git add . && git commit -m "..." && git push
  3. Wait for GitHub Pages to update
  4. Check the live site again

Build Failures in CI/CD

Symptom: GitHub Actions workflow fails after committing changes.

Common Causes:

  1. Site Validation Failures - The pre-commit hooks will catch these locally - CI runs python site/check_site.py --live as part of the build - Common failures: broken links, missing files, malformed HTML

  2. Build Script Errors - python site/build.py fails during HTML generation - Check for syntax errors in build.py or missing source files - Ensure all markdown files are valid and well-formed

  3. Missing Dependencies - Required packages not installed in CI environment - Run pip install -r requirements.txt in the workflow

  4. Permission Issues - Scripts lack execute permissions - Fix with: chmod +x .github/workflows/drift.yml (workflow files)

Solution:

  1. Run python site/check_site.py --live locally to catch issues before committing
  2. Check GitHub Actions logs for specific error messages
  3. Ensure all source files exist and are valid
  4. Verify dependencies are listed in requirements.txt

Prevention:

  • Pre-commit hooks will reject commits with validation failures
  • CI builds will fail if the site doesn't validate
  • Regular local builds catch issues early

Tool Issues

Tool Returns Unexpected Results

Symptom: A tool (e.g., read, write, run) doesn't work as expected.

Common Issues:

  1. Wrong Arguments - Check the tool's docstring for correct argument syntax - Use _run("python -c 'help(YourTool)'" to see docstrings
