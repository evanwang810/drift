# Metrics Dashboard Specification

## Overview

This dashboard visualizes productivity patterns over time by analyzing run data from RUNS.md and runs.json. It provides insights into token usage, turn counts, success rates, and project completion patterns.

## Data Sources

- **RUNS.md**: Master table of all runs with outcome, turns, tokens, and notes
- **runs.json**: JSON export of run data (generated by build.py)

## Metrics

### Basic Statistics
- Total runs completed
- Total days with runs
- Total tokens used
- Average tokens per run
- Maximum and minimum tokens in a single run
- Success rate (runs that stopped cleanly)

### Token Usage Analysis
- **Token Trends Over Time**: Line chart showing token usage per run (sampled every 10 runs to avoid clutter)
- **Peak Token Usage**: Highlight the highest usage run with run number

### Turn Distribution
- Bar chart showing how many turns are used per run (1-12 turns, with "12+" for longer runs)

### Outcome Distribution
- Bar chart showing the count of each outcome type (stopped, out_of_turns, out_of_time, api_error, crashed)

### Success Rate Over Time
- Line chart showing cumulative success rate per 50-run window (percentage of successful runs)

### Project Completion Tracking
- Count of runs where project completion was documented (identified by "done when" in the note)
- Percentage of runs with documented project completion

### Token Efficiency by Outcome
- Bar chart showing average tokens per turn by outcome type (only for runs with outcome data)

## Visualizations

All charts use inline SVG for portability:
- **Bar Charts**: Simple vertical bars with labels and values
- **Line Charts**: Polyline charts showing trends over time
- **Color Coding**: Consistent color scheme using CSS variables

## Technical Implementation

### Data Processing (build_metrics function)
1. Read and parse RUNS.md using existing `runs()` function
2. Sort runs by run number
3. Calculate all metrics programmatically
4. Generate SVG charts dynamically based on data

### Chart Generation
- `bar_chart()`: Creates horizontal bar charts
- `line_chart()`: Creates line charts with polyine elements

### HTML Structure
- Sectioned layout with clear headings
- Summary statistics in a `<dl class="stats">` list
- Each metric gets its own `<section>`
- Responsive design via CSS (inherited from site theme)
